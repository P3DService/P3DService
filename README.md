We build physical parts — and the tools that make production repeatable.

P3D Service brings together production 3D printing, 3D scanning, CAD and reverse engineering. We also develop software for equipment setup, device integration and workflow automation.

## Engineering

**3D printing** — functional prototypes, engineering polymers and small-batch production.

**3D scanning & CAD** — modelling, geometry reconstruction and reverse engineering.

## Software & automation

Deployment tools, equipment health checks and device integrations built around practical production needs: fewer repetitive steps, clearer system status and maintainable workflows.

## Featured public project

### [P3D K1 Deployment](https://github.com/P3DService/P3D-K1-Deployment)

Automated deployment, configuration and health validation for rooted **Creality K1C** and **Creality K1 Max** printers.

Repeatable setup, Fluidd provisioning, Moonraker Timelapse and QUICK/FULL health checks.
